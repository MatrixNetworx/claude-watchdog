# v5.3.1 — Rotation retention and integrity sampling

- Archives the oldest rotated event log under `~/WatchDog/archive/` before eviction, with SHA-256 sidecar. If archiving fails, rotation aborts rather than deleting evidence. Existing older files already deleted cannot be recovered by this update.
- Stable, descriptor-based hashing with retry for concurrent writers. Detects inode continuity across rotation filenames. `not_in_active_rotation` is a review notice, not evidence of deletion; compare archived files.
- Preserves existing integrity journal and checkpoints; no reset. A v5.3 checkpoint without `device` remains readable.
- A running process must be stopped before installing new executable files. Do not run setup. Restart both monitors after installation.
- SHA-256 sidecars and local checkpoints are not tamper-proof against an attacker with local write access. Keep off-host copies for stronger assurance.
- The historical 6,436 unmatched tool IDs are not automatically recovered.
